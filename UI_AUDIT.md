# UI baseline audit

## Keep

- Space Grotesk as the primary interface typeface
- Central project data and shared page container
- Strong project screenshots and direct case-study routes
- Dark canvas and restrained editorial composition
- Existing responsive project data and contact functionality

## Revise

- Replace mint, cyan and purple effects with the approved orange signal colour
- Reduce display sizes outside the hero
- Replace pill navigation and buttons with 4px to 8px geometry
- Present projects with technical metadata before category labels
- Replace the skills widget with a compact core-stack index
- Make page, visual and keyboard order identical
- Standardize action, border, focus and surface states

## Remove

- Custom cursor
- Ambient mesh and cursor-following glow
- Homepage particles and side progress rail
- Spider-Verse noise layering on the homepage
- Glassmorphism and large blurred shadows
- Continuous floating decorative motion
- 20px to 32px card radii
- Proficiency bars and launcher-style skill tiles

## Deferred to the case-study phase

- Legacy carousel styles
- Project archive card system
- Case-study page geometry and visual effects
- Route transition replacement

## Structural issues

- Homepage sections use CSS order instead of DOM order.
- Primary navigation order does not match the desired recruiter journey.
- Several unused animated hero components remain in the homepage module.
- Global CSS contains multiple generations of visual utilities.
- Metadata titles still lead with UX and design instead of development.
