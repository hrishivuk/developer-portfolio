# Portfolio design direction

## Creative position

An editorial product-design portfolio: calm enough to feel credible, expressive
enough to feel personal. The work remains the main visual content. Personality
comes through typography, writing, image composition and a restrained
Spider-Verse-inspired texture language.

## Experience principles

1. Communicate the role and value proposition within the first viewport.
2. Lead visitors toward selected work before asking them to make contact.
3. Use evidence—projects, decisions and outcomes—without duplicating the résumé.
4. Give every visual effect a job. Decoration should never compete with work.
5. Keep interactions understandable with a mouse, keyboard or touch.

## Visual system

- **Background:** warm near-black `#0b0c0b`
- **Primary text:** soft ivory `#f1efe8`
- **Secondary text:** warm grey `#c5c4bc`
- **Muted text:** `#8c8e87`
- **Accent:** restrained mint `#b9f6d2`
- **Display sans:** Space Grotesk
- **Surfaces:** two subtle elevation levels, defined mainly by border and tone
- **Texture:** faint grid, grain and halftone details used as atmosphere

## Typography rules

- Space Grotesk carries navigation, body copy, metadata and functional UI.
- Space Grotesk carries the full interface and keeps the identity direct.
- Avoid all-uppercase display headlines.
- Use uppercase only for short labels and metadata.
- Keep paragraph width close to 60–70 characters.

## Layout rules

- Use a consistent page container and section rhythm.
- Use one persistent pill navigation across every route.
- Keep `Projects`, `About` and `Contact` in the same position on every page.
- Keep contextual return actions inside page content rather than changing the navbar.
- Prefer strong alignment and negative space over extra decoration.
- Project imagery should occupy more visual weight than project metadata.
- Repeated cards must use equal heights, padding and image ratios.
- Mobile horizontal content needs a visible continuation cue.

## Motion plan

Motion is intentionally deferred until the static hierarchy is approved.

When implemented:

- Reveal content once, using short opacity and position transitions.
- Limit hover movement to 2–4px.
- Keep one signature interaction in the hero.
- Avoid continuously floating utility cards and unrelated ambient loops.
- Respect reduced-motion preferences everywhere.

## Content order

1. Positioning and primary action
2. About and working philosophy
3. Selected work with role and impact
4. How I work
5. Contact and résumé

## Quality bar

The Projects archive is the current component baseline: clear hierarchy,
consistent cards, deliberate spacing and project-first storytelling. New
homepage and case-study patterns should feel like part of the same system.

## Unified case-study pattern

Completed projects use one content framework regardless of discipline:

1. Hero with one-line context, role, timeline, scope and one primary action
2. Snapshot: challenge, response and no more than three contribution bullets
3. Three curated screens or interactions
4. No more than two meaningful decisions
5. One honest outcome and one reflection
6. Compact links to the full report, prototype, live product or repository

The portfolio page is the two-minute version of the story. Full research,
process, architecture, testing and feature inventories belong in supporting
material. Media art direction remains a separate phase; the structure works
with still images now and can support short product videos later.
